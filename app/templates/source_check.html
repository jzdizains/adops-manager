How a source reaches Glitchy
1. The ad's landing URL carries ?{{ param }}={{ '__CAMPAIGN_NAME__' if mode == 'campaign' else '' }} — this page checks that on TikTok itself.
2. TikTok fills in the value at click time and adds its own ttclid. The visitor lands on your prelander.
3. The pass-through script on the prelander and lander (Settings → Sources) carries {{ param }} through every link, form and JS redirect to the Glitchy offer link, packed as name~ttclid. If either page still runs an older script, or sends visitors on with a link the script can't see (a redirect on another domain, a button that builds its URL itself), the source is lost there — the “Test click” button reproduces exactly that path so you can watch the address bar.
4. Glitchy echoes it back in the postback; sourceless postbacks show up as unattributed on the P&L page and in the Inbox.
