The dashboard can run image AI through two providers. Each one needs its own key, added as an environment variable on Render — keys are never typed into the dashboard itself.

Higgsfield {{ '✓ connected' if hf_configured else '' }}

  1. Log in at higgsfield.ai → your avatar → API (or Developers) → Create API key. You get a Key ID and a Secret — copy both now, the secret is shown once.
  2. Make sure the account has API credits — the API bills per successful image in credits, separately from the web app's Unlimited plan.
  3. Open Render → this service → Environment → add HIGGSFIELD_KEY_ID and HIGGSFIELD_KEY_SECRET → Save. Render redeploys by itself (about a minute).
  4. Come back here: the Model list in “Generate with AI” and “Edit with AI” gains a Higgsfield group (Nano Banana, Soul, Popcorn, Reve, Flux Kontext).

Google (Nano Banana direct) {{ '✓ connected' if nb_only else '' }}

  1. aistudio.google.com → Get API key → create one for a project with billing enabled.
  2. Render → Environment → add GEMINI_API_KEY → Save.

Editing an image through Higgsfield sends it a temporary signed link to the source picture (valid 2 hours), so the dashboard's public address must be known — it learns it the first time Settings is opened.
